# AtkParam_Npc 参数含义完整推测

## 参数总览

AtkParam_Npc.csv 是只狼中的 **NPC 攻击参数表**，定义了游戏中所有 NPC 角色的攻击属性、伤害计算、击中判定、特效等核心战斗数据。

## 重要发现与推测总结

### 1. **碰撞系统**
- 支持最多 **16 个独立碰撞体**（hit0-hit15）
- 每个碰撞体可设置为**球体**（DmyPoly2=-1）或**胶囊体**（DmyPoly1+DmyPoly2）
- 通过**优先级**（Priority）解决多碰撞同时触发的冲突

### 2. **双重参数系统**
- **PC（玩家）**：使用 `xxxCorrection` 修正值（倍率）
- **NPC（敌人）**：使用绝对值（如 `atkPhys`、`atkMag`）
- 这种设计允许玩家伤害随装备/等级动态缩放，NPC 伤害固定

### 3. **体力（体幹）系统复杂度**
- 区分**攻击方体力削减**和**被体力削减**
- 细分**直击**、**弹刀胜利**、**弹刀失败**等多种场景
- 体现了只狼独特的**弹刀对峙**战斗核心

### 4. **格挡属性系统**
- 通过 `guardAttribute` 区分不同防御类型
- 允许攻击"破格挡"或"破完美格挡"的细粒度控制
- 支持区分普通格挡和完美格挡（ジャストガード）的不同反馈

### 5. **剑闪特效系统**
- 最多 **8 组剑闪轨迹**（trace 0-7）
- 每组通过**头尾绑定点**定义轨迹路径
- 用于生成华丽的武器挥舞光效

### 6. **音效/视效分离**
- **SFX**（视觉特效）和 **SE**（音效）独立控制
- 支持按**材质**、**尺寸**、**强度**、**方向**组合生成效果

### 7. **特殊效果槽位**
- 最多同时触发 **5 种特殊效果**（spEffectId0-4）
- 可实现中毒+出血+燃烧等复合异常状态

### 8. **振动反馈细节**
- 根据**命中部位**（先端/中段/根部）触发不同振动
- 提升战斗打击感的重要参数

## 使用建议

### 修改 NPC 伤害
修改 `atkPhys`（物理）、`atkMag`（魔法）等绝对值参数。

### 调整弹刀难度
修改 `guardAtkRate`（弹刀攻击力）和 `guardBreakRate`（弹刀防御力）。

### 增加攻击判定范围
调整 `hit0_Radius` 等半径参数，或增加碰撞体数量。

### 禁用某些防御机制
设置 `disableGuard_vsGuardAttribute0 = 1` 可让攻击无视普通格挡。

### 触发特殊效果
在 `spEffectId0-4` 中填入特殊效果参数ID（需配合 SpEffectParam 表）。

## 注意事项

1. **编码问题**：CSV 文件使用 Shift-JIS 编码，修改时注意保持编码一致
2. **枚举值**：部分参数使用枚举，需查阅对应枚举定义文件获取有效值
3. **关联参数**：许多参数需要配合其他参数表（如 SpEffectParam、ThrowParam）使用
4. **游戏平衡**：大幅修改可能破坏游戏平衡，建议小幅调整并测试
