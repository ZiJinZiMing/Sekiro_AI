## 概述

### 什么是 HitEffectSeHitWallParam？

**HitEffectSeHitWallParam** 是只狼音效系统中的**场景命中反馈矩阵**。它定义了当攻击（武器挥砍、子弹撞击、体术打击）命中**非角色物体**（如墙壁、地面、水面、木桶等）时播放的音效（SE）。

该系统通过“攻击属性”与“场景材质”的交叉索引，实现了高度真实的听觉反馈：

```
┌─────────────────────────────────────────────────────────────────────────┐
│                 HitEffectSeHitWallParam 的交叉索引逻辑                   │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                         │
│  攻击源属性 (来自 AtkParam / BulletParam)                                 │
│  ├─ 材质 (atkMaterial_forSe): Iron, Fire, Wood...                       │
│  ├─ 类型 (atkType): Slash, Thrust, Blow                                 │
│  └─ 大小 (atkSize): S, L, LL                                            │
│              ↓                                                          │
│  命中点材质 (来自地图 Collision 材质 ID)                                   │
│  └─ Row ID: 1 (石板), 4 (木材), 11 (铁), 20 (水)...                       │
│              ↓                                                          │
│  最终播放 SE ID (例如 200001)                                            │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘
```

## 核心参数结构

该表是一个庞大的横向矩阵，每一行代表一种**场景材质**，每一列代表一种**攻击组合**。

### 一、行标识 (被击物材质)

| 字段 | 含义 | 说明 |
|------|------|------|
| **ID** | 场景材质ID | 对应地图碰撞材质 ID。参考 `Names/HitEffectSeHitWallParam.txt` |
| **Name** | 材质名称 | 开发描述名 (如 Cobblestone, stone, wood) |

**常用 ID 示例**：
- **1-2**: 石质 (石板路、岩石)
- **3-13**: 土质/砂质 (泥土、沙地)
- **4, 8, 32**: 木质 (木材、树木、室内木板)
- **11, 106**: 铁质 (金属板、铁制物体)
- **20-22**: 水质 (积水、深水)
- **30**: 雪地

---

### 二、列分类 (攻击源属性)

列名采用 `{材质}_{类型}_{大小}` 的组合方式，决定了查询哪个字段。

#### 1. 攻击材质前缀 (AtkMaterial)
由 `AtkParam.atkMaterial_forSe` 或 `BulletParam.Material_AttackMaterial_forSe` 决定。

| 前缀 | 含义 | 对应武器/行为示例 |
|------|------|------------------|
| **Iron** | 铁制 | 楔丸、武士刀、手里剑、长枪 |
| **Fire** | 炎属性 | 火吹箭、附火攻击 |
| **Wood** | 木制 | 木槌、木质盾牌撞击 |
| **Body** | 肉体/体术 | 拳头、踢击、野兽撞击 |
| **Eclipse** | 蚀 (不死斩) | 不死斩挥砍、怨灵类攻击 |
| **Energy** | 能量/剑气 | 樱龙剑气、各类真空波 |
| **Maggot** | 蛆虫 | 附虫者相关的特殊粘稠攻击 |
| **Wax** | 蜡 | 源之宫相关特定敌人 |
| **FireFlame** | 烈焰 | 强力喷火、爆炸中心 |
| **EnergyStrong**| 强能量 | 强力冲击波 |

#### 2. 攻击类型中缀 (AtkType)
由 `AtkParam.atkType` 或 `BulletParam.Material_AttackType` 决定。

| 中缀 | 含义 | 说明 |
|------|------|------|
| **Slash** | 斩击 | 挥砍类动作 |
| **Thrust** | 刺突 | 突刺、箭矢穿透 |
| **Blow** | 打击 | 砸地、冲撞、钝器攻击 |

#### 3. 攻击大小后缀 (Size)
由 `AtkParam.atkSize` 或 `BulletParam.Material_Size` 决定。

| 后缀 | 含义 | 对应强度 |
|------|------|------|
| **_S** | 小 (Small) | 轻攻击、普通投射物 |
| **_L** | 大 (Large) | 蓄力重击、强力劈砍 |
| **_LL** | 特大 (X-Large)| 爆炸、Boss 落地、场景破坏 |

## 字段数值含义

表中的所有数值均为 **SE ID (s32)**，对应游戏音效引擎中的具体音频事件。

### 常用 SE ID 段位规律

- **20xxxx**: 铁器/金属类打击音。
- **21xxxx**: 刺突类音效。
- **22xxxx**: 钝击/打击类音效。
- **30xxxx**: 火焰/燃烧类音效。
- **40xxxx**: 木质碰撞音。
- **0**: 表示该组合下不产生特殊音效或使用默认兜底音。

## 设计意图与逻辑链路

### 1. 视听一致性
系统确保了不同材质的武器在不同材质的地面上会有完全不同的反馈。
*   **例子**：楔丸 (Iron) 砍在石头 (Cobblestone) 上是“锵”的金属撞击声，但砍在水面 (Water) 上则是“哗”的溅水声。

### 2. 性能与解耦
开发者不需要为每种场景材质写单独的代码逻辑。
*   **AtkParam** 只需描述自己：`我是铁(100), 斩击(1), 大号(2)`。
*   **物理引擎** 碰撞后告诉音效系统：`撞到了木头(4)`。
*   **音效系统** 自动匹配 `HitEffectSeHitWallParam[4]["Iron_Slash_L"]` 并播放。

### 3. 反射与混合
虽然该表主要处理 SE ID，但实际上在引擎内部会结合 `AtkParam` 中的 `atkPow_forSe` 进行音量加权，或者结合 `spAttribute` 播放额外的属性音效。

## 关联参数表

| 参数表 | 关联字段 | 作用 |

| **AtkParam_Npc/Pc** | `atkMaterial_forSe`, `atkType`, `atkSize` | 提供查询矩阵的列索引 |

## 修改建议

1. **增强打击感**：
   如果觉得某种武器砍墙的声音太小，可以在 `AtkParam` 中将其 `atkSize` 从 S(0) 改为 L(1) 或 LL(2)。
2. **特殊武器音效**：
   如果制作了“雷电”武器，可以将 `atkMaterial_forSe` 设为 `ENERGY`，并在该表的 `Energy_...` 列中填入电流撞击的 SE ID。
3. **静音处理**：
   将对应单元格设为 `0` 或 `-1` 即可消除特定材质碰撞的声音。
