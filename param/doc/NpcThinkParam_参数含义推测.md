# NpcThinkParam.csv 参数含义推测文档

本文档基于 `NpcThinkParam.xml` 定义文件对 NpcThinkParam.csv 中的参数进行全面分析。

**NpcThinkParam** 是只狼中控制 **NPC AI思考逻辑** 的核心参数表，负责感知系统、寻路行为、队伍协作等。

---

## 一、基础标识参数

| 参数名 | 数据类型 | 推测含义 | 推测依据 |
|--------|----------|----------|----------|
| ID | s32 | 思考参数唯一标识符 | CSV主键，NPC通过此ID引用思考配置 |
| Name | string | 思考参数名称/描述 | 包含日英文描述，如"for test -- テスト用" |
| logicId | s32 | 逻辑脚本ID | XML: "スクリプトで作成したロジックのIDを設定します"，指向Lua逻辑脚本，-1为不使用 |
| battleGoalID | s32 | 战斗Goal ID | XML: "戦闘ゴールID"，战斗行为的Goal标识，-1为不使用 |

## 总结

**NpcThinkParam** 是只狼AI系统的**感知与决策核心**，共约110个参数，覆盖以下子系统：

### 核心AI系统

1. **三层视觉系统**
   - **认识（Perceive）** - 首次发现敌人，视野最广
   - **通常（Normal）** - 日常巡逻，视野中等
   - **周边（Around）** - 周边警戒，视野较窄但全方位

2. **多感官感知系统**
   - **视觉** - 视锥检测，带角度、距离、盲区
   - **听觉** - 球形检测，带噪音过滤
   - **嗅觉** - 球形检测，近距离感知

3. **渐进式发现系统**
   - 发现点数积累机制
   - 不同感知源有不同积累速度
   - 达到阈值才进入战斗

4. **回巢机制（Leash系统）**
   - 三档距离：边战边撤、死战、强制回巢
   - 回巢过程中的注视与防御行为

5. **仲间呼叫系统**
   - 组ID分组机制
   - 距离限制与动作触发
   - 小队延迟响应

6. **导航网格权限系统**

7. **Goal动作系统**

- **callHelp_*** → 触发队伍协作行为
- **goalAction_*** → 触发Goal层行为切换
