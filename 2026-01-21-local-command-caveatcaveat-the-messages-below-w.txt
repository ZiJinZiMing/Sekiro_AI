  stateInfo 详解                                                                
                                                                                
  1. stateInfo 是什么？                                                         
                                                                                
  stateInfo 是 SpEffectParam 表中的一个 u16                                     
  类型字段（日文名：状態変化タイプ），用于定义 SpEffect                         
  的行为类型分类。它决定了当该特效被施加时，系统应该如何处理它。                
                                                                                
  关键枚举值 (SP_EFFECT_TYPE)：                                                 
  值: 0                                                                         
  名称: None                                                                    
  说明: 无特殊类型                                                              
  ────────────────────────────────────────                                      
  值: 2                                                                         
  名称: Poison                                                                  
  说明: 毒状态                                                                  
  ────────────────────────────────────────                                      
  值: 5                                                                         
  名称: Terror                                                                  
  说明: 恐怖状态                                                                
  ────────────────────────────────────────                                      
  值: 6                                                                         
  名称: Burn                                                                    
  说明: 燃烧状态                                                                
  ────────────────────────────────────────                                      
  值: 120                                                                       
  名称: Damage Level Change (pre-poise)                                         
  说明: 破防前伤害等级变更                                                      
  ────────────────────────────────────────                                      
  值: 152/153                                                                   
  名称: Enable Attack Effect                                                    
  说明: 启用攻击效果（配合 atkSpEffectId）

  2. stateInfo 如何参与战斗伤害流程？                                           
                                                                                
  graph TD                                                                      
      A[攻击命中] --> B[AtkParam.spEffectId]                                    
      B --> C[SpEffectParam 被施加]

      F --> I[env 3041 STATUS_BURNING == TRUE]                                  
                                                                                
      H --> J[GetSpDamage 返回 SP_DAMAGE_POISON_REACTION]                       
      I --> K[GetSpDamage 返回 SP_DAMAGE_BURNING]

  4. 在 ExecDamage 流程中的作用                                                 
                                                                                
  stateInfo → STATUS_* → SP_DAMAGE_* → ExecDamage 处理链：                      
                                                                                
  -- ExecDamage 处理链（c9997.dec.lua）                                         
  function ExecDamage(transition_rank)                                          
      local pre_sp_damage = GetSpDamage()  -- 这里会检查 env(3041, STATUS_*)    
                                                                                
      -- 按优先级调用处理函数                                                   
      if ExecDebuffReaction(damage_level, pre_sp_damage, transition_rank) ==    
  TRUE then                                                                     
          return  -- 处理燃烧/中毒反应                                          
      end                                                                       
      -- ... 其他处理                                                           
  end                                                                           
                                                                                
  function ExecDebuffReaction(damage_level, pre_sp_damage, transition_rank)     
      -- SP_DAMAGE_BURNING (由 stateInfo=6 触发)                                
      if pre_sp_damage == SP_DAMAGE_BURNING then                                
          Fire("W_FireReaction")  -- 播放燃烧受击动画                           
          return TRUE                                                           
      end                                                                       
                                                                                
      -- SP_DAMAGE_POISON_REACTION (由 stateInfo=2 触发)                        
      if pre_sp_damage == SP_DAMAGE_POISON_REACTION then                        
          Fire("W_SpecialPoisonReaction")  -- 播放中毒反应动画                  
          return TRUE                                                           
      end                                                                       
  end

  积系统关联，最终在 ExecDamage 中触发对应的伤害反应。

  重新分析：stateInfo 的真正功能                                                
                                                                                
  1. stateInfo 的本质                                                           
                                                                                
  根据 Meta/SpEffect.xml 中的 Wiki 说明：                                       
                                                                                
  "Handles various hardcoded actions (not all stateInfos have hardcoded         
  actions). Can also be used to apply conditional effects."                     
                                                                                
  翻译：处理各种硬编码的引擎行为（不是所有 stateInfo                            
  值都有硬编码行为）。也可用于应用条件效果。                                    
                                                                                
  2. stateInfo 的核心作用                                                       
                                                                                
  stateInfo 是一个引擎层面的"效果分类标识符"，它告诉引擎如何处理这个 SpEffect： 
  ┌──────────────┬───────────────────────────┬───────────────────────────────┐  
  │ stateInfo 值 │           名称            │        引擎硬编码行为         │  
  ├──────────────┼───────────────────────────┼───────────────────────────────┤

  ├──────────────┼───────────────────────────┼───────────────────────────────┤

  ├──────────────┼───────────────────────────┼───────────────────────────────┤  
  │ 5            │ Terror                    │ 累积恐怖槽 → 满后即死         │  
  ├──────────────┼───────────────────────────┼───────────────────────────────┤

  graph TD

  5. 关键区分                                                                   
                                                                                
  stateInfo ≠ 直接的状态标志                                                    
                                                                                
  - stateInfo 是配置层的分类标识，告诉引擎"这个 SpEffect 属于什么类型"          
  - STATUS_* 是运行时的状态查询，表示"角色当前是否处于某状态"                   
  - 两者通过引擎的状态累积系统关联                                              
                                                                                
  SpEffect.stateInfo = 6 (Burn 类型标识)                                        
      ↓ 引擎处理                                                                
  累积燃烧槽 → 槽满 → 设置状态标志                                              
      ↓                                                                         
  env(3041, STATUS_BURNING) = TRUE (运行时状态)                                 
                                                                                
  6. stateInfo 如何参与伤害计算                                                 
                                                                                
  stateInfo 本身不直接参与伤害计算，但它通过以下方式间接影响：                  
                                                                                
  1. 状态异常触发 - stateInfo=2/5/6/116/260 等会触发状态累积系统                
  2. 状态异常伤害 - 状态满后，GetSpDamage() 检测到状态，返回对应的 SP_DAMAGE_*  
  3. 伤害处理链 - ExecDamage 根据 SP_DAMAGE_* 类型调用对应的处理函数            
  4. 条件效果链 - invocationConditionsStateChange1/2/3 可以检查目标的           
  stateInfo，作为触发后续效果的条件                                             
                                                                                
  7. 在 ExecDamage 中的作用                                                     
                                                                                
  stateInfo 不直接被 ExecDamage 读取，而是通过状态系统间接影响：                
                                                                                
  -- c9997.dec.lua GetSpDamage() 函数                                           
  -- 检查的是状态结果，而非 stateInfo 配置值                                    
  if env(3041, STATUS_BURNING) == TRUE then  -- 检查燃烧状态                    
      ret = SP_DAMAGE_BURNING                                                   
  end                                                                           
                                                                                
  if env(3041, STATUS_SPECIAL_POISON) == TRUE then  -- 检查中毒状态             
      ret = SP_DAMAGE_POISON_REACTION                                           
  end
